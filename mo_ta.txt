# Fleet & Workshop Management System (Taxi + Service Center)

Bạn là Kiến trúc sư phần mềm Senior Fullstack.

Hãy xây dựng một hệ thống Web Portal Enterprise cho doanh nghiệp vận hành Taxi điện và Xưởng Dịch vụ bảo dưỡng xe điện VinFast.

## Công nghệ bắt buộc

### Backend

* Node.js 22+
* NestJS
* PostgreSQL 16
* Prisma ORM
* JWT Authentication
* RBAC Permission
* Redis Cache
* Bull Queue
* Swagger API

### Frontend

* NextJS 15
* TypeScript
* TailwindCSS
* Shadcn/UI
* Tanstack Table
* Recharts
* React Query
* Zustand

### DevOps

* Docker
* Docker Compose
* Nginx
* PM2
* GitHub Actions CI/CD

## Chuyển đổi phụ tùng giữa xe

Tính năng đặc biệt.

Ví dụ:

Xe A đang chờ phụ tùng.

Cho phép lấy phụ tùng từ:

* Xe B
* Xe C

và ghi nhận:

* Xe nguồn
* Xe nhận
* Phụ tùng
* Người duyệt
* Lý do

Lưu toàn bộ lịch sử.

Audit log bắt buộc.
